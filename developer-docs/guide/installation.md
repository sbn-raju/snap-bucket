# Installation Guide

Snap Bucket is distributed across two separate npm packages tailored for your stack.

---

## 💻 Frontend Client Setup

In your frontend application directory (supporting frameworks like React, Vue, Svelte, Vite, Next.js, or SolidJS):

::: code-group

```bash [npm]
npm install snap-bucket
```

```bash [yarn]
yarn add snap-bucket
```

```bash [pnpm]
pnpm add snap-bucket
```

:::

---

## ⚙️ Backend Server Setup

In your Express or Node.js server directory:

::: code-group

```bash [npm]
npm install snap-bucket-server
```

```bash [yarn]
yarn add snap-bucket-server
```

```bash [pnpm]
pnpm add snap-bucket-server
```

:::

---

## Peer Dependencies

Ensure your project environment supports the following baseline engines:
* **Node.js**: `>=18.0.0`
* **TypeScript** (*optional*): `>=5.0.0` (for full typesafety integration)
